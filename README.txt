CARA MENJALANKAN APLIKASI:
1. Pastikan XAMPP (Apache & MySQL) sudah berjalan.
2. Pindahkan folder proyek ini ke dalam folder 'htdocs' di XAMPP Anda.
3. Buka phpMyAdmin di browser (http://localhost/phpmyadmin).
4. Buat database baru dengan nama: store_db
5. Import file SQL yang ada di dalam folder `database/store_db.sql` ke dalam database tersebut.
6. Buka browser dan akses aplikasi melalui URL:
   http://localhost/manajemen_produk/public/index.php
